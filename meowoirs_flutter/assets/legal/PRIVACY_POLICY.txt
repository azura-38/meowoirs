1. INTRODUCTION & SCOPE
================================================================================
Welcome to Meowoirs ("Application"). This Privacy Policy explains how information is handled when you download, install, and use the Meowoirs mobile application on Android devices (package identifier: com.limanex.meowoirs).

Meowoirs is designed as a personal, local-first cat memory journal. We prioritize your privacy through architecture: your personal journal content stays on your physical device and is not collected, stored, or synchronized on remote LIMANEX servers.

By installing, accessing, or using Meowoirs, you acknowledge the practices described in this Privacy Policy.

3. DEFINITIONS
================================================================================
- "Application" or "Meowoirs" means the Meowoirs Android mobile software application.
- "User", "you", or "your" means any individual accessing or using the Application.
- "Device" means the physical Android device on which Meowoirs is installed.
- "User Content" means all cat profiles, names, notes, journal entries, mood selections, and photos inputted or selected by the User.
- "Local Storage" means the embedded SQLite database (managed via AndroidX Room) and local preferences (managed via AndroidX DataStore) residing within the private application sandbox on your Device.
- "Third-Party Service" means external software development kits integrated for advertising and stability, specifically Google Mobile Ads (AdMob), Google User Messaging Platform (UMP), and Firebase Crashlytics.

================================================================================
4. WHAT MEOWOIRS STORES LOCALLY ON YOUR DEVICE
================================================================================
Meowoirs operates on a local-first architecture. All user-created journal entries, cat information, and preferences are stored exclusively on your physical Android Device in local SQLite/Room database files and local DataStore files:

1. Cat Profiles:
   - Cat name
   - Classification (Home Cat or Street Cat)
   - Photo reference (local content URI selected via system Photo Picker)
   - Cat profile note
   - Creation timestamp

2. Memories (Journal Entries):
   - Associated cat identifier and cat name
   - Journal note text
   - Memory photo reference (local content URI)
   - Cat mood reflection selection (e.g., Happy, Curious, Sleepy, Playful, Calm, Affectionate)
   - User mood reflection selection (e.g., Happy, Peaceful, Nostalgic, Joyful, Calm, Touched)
   - Creation timestamp

3. Profile & Display Preferences:
   - User nickname
   - Selected avatar identifier
   - Favorite cat identifier
   - Theme mode preference (System, Light, Dark)
   - Interface language code
   - Onboarding completion flag and accepted legal version

================================================================================
5. WHAT WE DO NOT COLLECT OR STORE REMOTELY
================================================================================
LIMANEX does NOT operate a cloud backend server or remote database for your journal records. Meowoirs does NOT collect, require, transmit, or store:
- User accounts, logins, usernames, or passwords
- Real personal names, email addresses, or phone numbers
- Cloud synchronization across multiple devices
- Automated remote cloud backups of journal entries
- Contact lists or address book records
- Audio recordings or microphone input
- Precise or coarse GPS hardware location data
- Camera sensor access (Photo Picker is used instead)
- Veterinary or clinical medical health records

Your journal entries, notes, photos, and reflections exist solely on the Device where they were entered.

================================================================================
6. PHOTO PRIVACY & PHOTO PICKER
================================================================================
Meowoirs uses Android's native system Photo Picker (ActivityResultContracts.PickVisualMedia) whenever you attach an image to a cat profile or memory:
- The Application does NOT request broad storage or media permissions (such as READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE, READ_MEDIA_IMAGES, or READ_MEDIA_VIDEO).
- The Application does NOT request CAMERA hardware permission.
- The Application does NOT scan or continuously access your photo library.
- Only individual images you explicitly choose in the system picker are accessible to Meowoirs, referenced via system-managed content URIs stored locally.

================================================================================
7. DATA DELETION & RETENTION ARCHITECTURE
================================================================================
- In-App Deletion: When you delete a memory or cat profile using the in-app delete buttons, the corresponding record is immediately removed from the local SQLite/Room database on your Device.
- Permanent Loss: DELETED CONTENT MAY BE PERMANENTLY LOST. Because LIMANEX does not operate a remote server or maintain cloud backups of your journal content, LIMANEX has no technical ability to restore, recover, or reconstruct deleted entries.
- Local Data Removal & Android Backup: Meowoirs does not operate its own cloud backup or synchronization service. Clearing application data or uninstalling the application may remove locally stored Meowoirs data. Android or device-level backup and restoration behavior, where available, is controlled by the operating system and device configuration and is not operated or guaranteed by LIMANEX.
- User Backup Responsibility: You are solely responsible for maintaining independent backups of any photos, notes, or memories you consider irreplaceable.

================================================================================
8. CAT DELETION BEHAVIOR
================================================================================
In accordance with Meowoirs' current database design:
- Deleting a cat profile removes that cat's record from your cat collection.
- Deleting a cat does NOT delete associated memory entries; journal memories remain preserved in your memories collection so your personal journal history is not unintentionally wiped out.
- If the deleted cat was set as your Favorite Cat, that preference is automatically cleared.
